🧠 Quiz Generator App

A simple and interactive Quiz Generator web application that allows users to answer multiple-choice questions and get instant results. Built as a part of my web development practice/internship project.

🚀 Features
🎯 Multiple-choice quiz questions
⚡ Instant score calculation
📊 Final result display
🎨 Clean and responsive UI
🔄 Easy to add more questions
💡 Beginner-friendly design

🛠️ Tech Stack
HTML
CSS
JavaScript

Open the project folder
Run index.html in your browser

🎮 How It Works
Users start the quiz
Each question has multiple options
User selects an answer
App calculates score at the end
Final result is displayed instantly
